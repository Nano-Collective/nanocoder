Added a first-class provider template for Runcrate, a GPU cloud that serves open models on an OpenAI-compatible API, to the `/settings providers` wizard. Selecting it fills in the base URL (`https://api.runcrate.ai/v1`) so only an API key and a model name (for example `deepseek-ai/DeepSeek-V4.1-Flash`) are needed.
