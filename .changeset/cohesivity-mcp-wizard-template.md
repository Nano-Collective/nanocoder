The MCP setup wizard (`/settings mcp`) now offers a **Cohesivity** template on the remote servers tab. It builds a remote HTTP MCP config pointing at `https://cohesivity.ai/mcp`, so the agent can set up a backend for the project it is working on: hosting, Postgres, auth, storage and more. No API key is needed.
