Add auto-format-on-save. A new `nanocoder.autoFormat` section in `agents.config.json` runs a configured formatter command against any file successfully touched by `write_file` or `string_replace` at the end of each turn, so agent-generated whitespace and style drift gets cleaned up without spending model tokens on it. Each entry in `formatters` binds a list of file extensions to a shell command containing a `{file}` placeholder (e.g. `{"extensions": ["ts", "tsx"], "command": "npx prettier --write {file}"}`); the first formatter whose extensions match the edited file's extension runs, with `{file}` substituted for the shell-quoted absolute path. Disabled by default (`enabled: false`, no formatters) — running arbitrary shell commands against edited files is opt-in. A formatter failure (non-zero exit, missing binary, or exceeding `timeoutMs`, default 10000ms) is reported as a chat message but never blocks the conversation or gets reported back to the model, matching the "similar wiring, non-fatal failures" shape requested in the issue.
