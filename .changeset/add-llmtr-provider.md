Added a first-class provider template for LLMTR, a prepaid OpenAI-compatible gateway, to the `/settings providers` wizard. Selecting it fills in the base URL (`https://llmtr.com/v1`) so only an API key and a model name (for example `qwen/qwen3.8-27b-free`) are needed.
