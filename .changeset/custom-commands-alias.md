`/custom-commands`, the old name of `/commands`, is now an alias for it like the other old command names. Before, only `/custom-commands create <name>` still worked and any other use reported `Unknown command`. Now `/custom-commands` lists your commands, `/help custom-commands` opens the `/commands` page, and a fully typed `/custom-commands` completes to itself in the slash menu.
