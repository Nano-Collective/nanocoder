The `?` keyboard shortcuts overlay now lists the bindings it was missing: Ctrl+Z / Ctrl+Y undo and redo, Ctrl+← / Ctrl+→ word jumps, picking a queued message with Down and then editing it with Enter or removing it with Delete, PgUp / PgDn and the mouse wheel for scrolling the fullscreen transcript, and Esc returning a prompt to the input when the response hasn't started yet. The task list hint in the status line now reads `Ctrl+T`, matching the overlay, instead of `Ctrl-t`.
